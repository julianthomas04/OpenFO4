# 07.11.2026 (0.2.0-alpha)

## Features
- Added a day-night cycle
- Added a weather cycle
- Updated visuals: sky gradient and sun disc, height fog, interior fog, god rays, sun and ambient light, tone mapping, colour grading and auto exposure
- Added both types of loading screens
- Full loading process is now hidden behind a loading screen
- Physics objects can now be picked up and thrown

## Bug fixes
- Walk-in entrances now work
- Diamond City and Goodneighbor can now be entered and exited
- Worldspaces now use the terrain of their parent worldspace
- Lights now have smooth edges
- Progress bars in the installer now progress linearly
