ship inside the unpacked folders named here (under %LOCALAPPDATA%\OpenFO4\installer\<version>-<id>\). The generated
legal\COMPONENT_INDEX.txt lists the exact component versions, license evidence, source origins and modifications.

The installer program uses .NET, Avalonia UI, SkiaSharp, HarfBuzzSharp, SQLite, Mutagen and other packages. Their individual
licenses and retained notices are indexed in legal\COMPONENT_INDEX.txt. The self-contained .NET runtime's actual runtime-pack
LICENSE.TXT and THIRD-PARTY-NOTICES.TXT accompany both .NET programs; source-repository MIT labels do not replace binary notices.

The game executable is installed into the folder you choose.

Matching source download
------------------------
Download OpenFO4-<version>-sources.zip from Assets on the same GitHub release as the normal installer. The release notes link
that source asset near the bottom. OpenFO4-<version>-release-manifest.json pairs the installer and source archive by SHA256 and
source commit. The source archive contains preferred source, retained licenses, build scripts, and required dependency sources;
it is a separate download and is not embedded in the normal installer. Build SDKs are documented prerequisites; no complete
compiler/SDK source closure is claimed.
