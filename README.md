# OpenFO4
Version 0.1.0-alpha

## About
OpenFO4 aims to rewrite the engine of Fallout 4 to achieve greater performance, higher stability, fewer bugs, and improved modability. It uses the Fallout 4 assets but apart from that, everything else is new.

## What to expect
As of version 0.1.0-alpha you can spawn into the Commonwealth at one of multiple pre-selected locations (note that load times are high when you spawn in a new location for the first time. On subsequent spawns there, the load times drastically reduce). You can walk around the map, as well as enter interiors (Diamond City and Goodneighbor cannot be entered the normal way yet) and interact with physics objects. The game also features an extensive developer menu with which you can freely play around (any changes you make are discarded after a restart).

## How to play
### Prerequisites:
- Windows 11 (older versions of Windows, as well as other operating systems are untested and unlikely to work out of the box).
- A copy of Fallout 4 installed on your machine.
- You must have launched Fallout 4 at least once before (as this generates additional configuration files OpenFO4 requires).
### Installation:
- Head to [GitHub Releases](https://github.com/julianthomas04/OpenFO4/releases/latest) and download the installer.
- Once downloaded, run the installer. Set where you want the game to be installed (and where the Fallout 4 game files currently are, if the installer did not detect them).
- Press 'Install'. This will build the new installation from your Fallout 4 install. The Fallout 4 game files won't be affected and you can still play it normally afterwards. This step can take a while. Note that some errors in the console of the installer are to be expected.
- Once the installer has finished, hit 'Play'.
